# Compreensão e vocabulário contextual

**Quando usar:** análise de letras, dificuldades de interpretação, tradução, seleção de expressões.

1. Peça primeiro compreensão livre sem tradução. Em seguida, pergunte sobre trechos curtos ou sobre o tema, sem revelar toda a resposta.
2. Revele o significado **gradualmente**. Explore contexto, aspecto verbal, phrasal verbs, conectores, colocação e registro informal.
3. Escolha **5 a 8 chunks** úteis para comunicação real; anote significado, contexto, frase feita pelo aluno, correção e evidência real.
4. Para cada chunk: pedir hipótese → explicar se necessário → pedir frase própria → corrigir → testar com outro contexto.
5. Utilize exercícios variados: completar, traduzir PT→EN e EN→PT, explicar, reformular, contrastar registros, escolher entre opções.
6. Prefira compreensão e uso espontâneo a decorar a letra. Teste em outros contextos e com materiais inéditos.
7. Chame `$automatic-notes` para salvar progresso; use `note add --type expression` e `--type grammar` somente após obter dados reais.

**Direitos autorais:** o usuário pode trazer uma letra para estudo no chat; não gere arquivos redistribuíveis com letra integral ou longos blocos protegidos. Salve metadados, referência e explicações próprias.
