# Adaptação pedagógica

**Quando usar:** resposta errada, muita facilidade, repetição de falhas, dificuldade auditiva ou mudanças no objetivo.

1. Identifique tipo de falha: compreensão, memória, gramática, pragmática, audição, pronúncia (esta só com áudio), produção.
2. Selecionar intervenção: explicação curta, contraste com exemplo, frase com lacuna, nova tradução, interpretação de outro trecho, produção espontânea, reutilização em conversa.
3. Não repetir apenas a mesma pergunta com pistas crescentes; **retente em novo contexto**.
4. Reavaliar imediatamente e registrar evidência e correção com `song checkpoint`. Escalonar para revisão posterior se tempo se esgotar.
5. Para domínio consistente, aumentar naturalmente complexidade, velocidade de áudio, abstração e liberdade de produção sem saltos arbitrários.
6. Replanejar fases via `$learning-roadmap` se resultados cumulativos indicarem atraso ou aceleração, preservando histórico.

**Regras:** respeitar o orçamento de sessão, nunca fabricar progresso, não fixar nível B1 nem prazo de 90 dias, não desviar do tema principal de um chat para uma segunda música.
